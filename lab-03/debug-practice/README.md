# Debug practice: broken copy of Lab 3

This folder is a copy of the Lab 3 server with **four planted bugs**, like the exercise the faculty hands out. Find and fix each one *before* opening `ANSWERS.md`.

```bash
cd lab-03/debug-practice
npm install
npm run setup
npm start
```

Work through the errors in the order they appear. After each fix, restart and read the new error.
Compare with `../index.js` (the working version) only when you are stuck.
